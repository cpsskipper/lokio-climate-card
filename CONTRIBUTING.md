# Contributing

Contributions and bug reports are welcome.

Before opening a pull request:

1. Keep the card dependency-free unless a dependency is clearly necessary.
2. Do not commit real Home Assistant entity IDs, access tokens, local URLs, or secrets.
3. Run `npm run check`.
4. Keep `lokio-climate-card.js` and `dist/lokio-climate-card.js` identical.
5. Update `CHANGELOG.md` when behavior or configuration changes.

For bug reports, include the card version, Home Assistant version, a minimal anonymized YAML configuration, and browser console errors when relevant.
